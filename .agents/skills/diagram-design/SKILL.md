# Diagram Design Skill

Design clean, editorial-grade technical diagrams following modern visual standards:
- Clear visual hierarchy with distinct containers and layers.
- Strict color tokens (avoiding random neon colors).
- Explicit coordinate alignment and generous spacing.
- Clean typography and crisp SVG arrows with markers.
